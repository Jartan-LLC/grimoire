# 14: The statement parser breaks without anyone noticing

The bank has changed its export format twice this year. Both times `parse_line` in
`ledger/parse.py` started rejecting or misreading lines, and we only found out when the
month's totals were wrong.

Nothing checks the parser today. We want to know straight away when it stops handling:

- ordinary lines, debits and credits;
- malformed lines: wrong number of fields, a bad date, a bad amount, an empty payee;
- currencies: JPY takes no decimals, EUR and USD take two, and an unknown currency is
  rejected.

The parser itself is right as far as we know; this is about catching the next break.

# 2026-10-12: stock levels stale for six hours

## Summary

The stock import read the supplier feed from an old URL after the supplier moved it, found no
rows, and kept yesterday's levels. Pickers worked from stale counts from 06:00 to 12:10.

## Timeline

- 06:00 -- the import runs and finds an empty feed; no alert, because an empty feed is not an error.
- 11:40 -- the warehouse reports counts that do not match the shelves.
- 12:10 -- the feed URL is updated and the import rerun by hand.

## Impact

Fourteen orders were picked short and shipped a day late.

## Follow-ups

1. Treat an empty supplier feed as a failure and alert on it. (Done, 2026-10-14.)
2. Ask the supplier to announce URL changes in advance. (Ops.)

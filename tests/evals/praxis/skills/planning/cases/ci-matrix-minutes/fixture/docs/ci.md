# CI

This repository is private. Our GitHub plan includes 3,000 Actions minutes a month, and
October used 2,400.

Linux minutes count once, Windows minutes count twice and macOS minutes count ten times
against the plan. Minutes past the plan are billed at $0.008 per Linux minute ($0.016
Windows, $0.08 macOS).

The test job takes about 12 minutes, and it runs about 200 times a month.

# subkit

A small subtitle library: cues in, cues out, in whichever format a video player or an editor wants.
Times are whole milliseconds from the start of the video.

The shared types are in `subkit/model.py`; specs for each feature are under `docs/`.

## Development

Python 3.11 or later, standard library only; the tests need pytest.

    python3 -m pytest
